# Provider scripts

This folder contains provider-specific activation and inventory commands.

- `codex_activate_task.py`: activates or clears the Codex task binding.
- `codex_inventory.py`: refreshes and displays Codex-visible model inventory.
- `opencode_activate_task.py`: activates or clears the OpenCode task binding.
- `opencode_inventory.py`: displays the OpenCode runtime inventory and overrides.
- `README.md`: explains provider-script responsibilities.
