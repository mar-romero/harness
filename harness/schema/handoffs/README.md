# Handoff schemas

- `explorer.schema.json`: explorer facts, unknowns, risks, and files.
- `implementation-result.schema.json`: changed files, checks, and residual risks.
- `plan.schema.json`: ordered plan, acceptance, risks, and rollback.
- `review.schema.json`: independent review findings and evidence.
- `security-review.schema.json`: trust boundaries, findings, and residual risk.
- `test-audit.schema.json`: audited tests, gaps, and findings.
- `test-design.schema.json`: behaviors, oracle, and test cases.
- `verification.schema.json`: criterion-by-criterion verification evidence.
