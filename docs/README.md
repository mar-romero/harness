# Documentation

This folder contains explanatory and operational documentation for the harness.

- `MODEL_ROUTING.md`: model availability, score provenance, and routing.
- `RESEARCH_DRIVEN_DEVELOPMENT.md`: pre-implementation research workflow.
- `RECEIPT_DRIVEN_DEVELOPMENT.md`: post-check review integrity workflow.
- `README.md`: explains the documentation boundary.

Documentation does not directly change execution; executable contracts live in
`AGENTS.md`, `AI_POLICY.md`, `harness/`, and `scripts/`.

- `NEUTRAL_CHAT.md` — provider-neutral terminal chat and automatic multi-provider orchestration.
- `UNIFIED_HARNESS.md` — all-in-one CodeGraph/context, subscription runtime, canonical skills/hooks/ACI, and neutral terminal architecture.
