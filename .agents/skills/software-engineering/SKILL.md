# software-engineering

Optimize for correctness, legibility, cohesion and small reversible changes. Use YAGNI and avoid speculative abstraction. Preserve existing contracts unless change is explicit. Validate boundary inputs, make failure behavior explicit, control nondeterminism in tests and prefer dependency injection only when it solves a demonstrated seam. Security-sensitive code requires least privilege and untrusted-input handling. Read only relevant references.
